# Pilot feedback template

Use after a real session (project created or booking attempted). Do not ask whether they “like the app.”

Participant: _______________  
Role: Planner / Vendor / Admin  
Date: _______________  
Event type / city: _______________

## Behavior observed (operator fills this)

- [ ] Created a project  
- [ ] Searched products  
- [ ] Opened a vendor profile  
- [ ] Checked availability  
- [ ] Added a product to a project  
- [ ] Sent a booking request  
- [ ] Vendor responded  
- [ ] A booking was confirmed  
- [ ] Returned to FlowSet later  

## Questions

1. What was the most useful part of FlowSet?

2. What was confusing?

3. What did you previously do using WhatsApp or calls?

4. What saved you the most time?

5. What information was missing?

6. Would you use this for your next event? Why or why not?

7. Would you pay for this? What would you pay for (planner seat, vendor listing, neither)?

8. What would make you use it every week?

9. What did you expect FlowSet to do but it didn't?
